# FIRST X&XI — visual editing edition

Start with **START-HERE.md** for GitHub, TinaCMS, and Vercel setup.

The original HTML/CSS design is retained. Vite builds the site and a React bridge enables Tina's live visual editing. Editable content is versioned in GitHub. No database or custom login server is required.

Fonts and their SIL licenses are in `public/assets`. Photos remain external Unsplash references, replaceable through the editor. The recreated text logo remains the default until the original is uploaded. The contact form prepares email drafts; it does not submit data to a server.

Use `OPEN-PREVIEW.html` for a simple double-click visual preview. Do not expect the source `index.html` to work directly from disk in this build-based edition.
